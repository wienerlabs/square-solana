## Yöntem
BC-05 ile aynı: `git subtree` yerine `git filter-repo` (taze klonda).

```bash
git clone https://github.com/wienerlabs/aperture.git <tam-klon>
git clone --no-local <tam-klon> <geçici-dizin>
cd <geçici-dizin>
git filter-repo --path circuits/payment-prover/ \
  --path-rename circuits/payment-prover/:circuits/payment-compliance/
# square-solana'da:
git fetch <geçici-dizin> HEAD
git merge --allow-unrelated-histories FETCH_HEAD
```
