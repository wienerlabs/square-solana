## Yöntem

BC-05 ile aynı: `git subtree` yerine taze klonda `git filter-repo`.

```bash
git clone --no-local <tam-klon> <geçici-dizin>
cd <geçici-dizin>
git filter-repo --path services/prover-service/ \
  --path-rename services/prover-service/:apps/prover/
# square-solana'da:
git fetch <geçici-dizin> HEAD
git merge --allow-unrelated-histories FETCH_HEAD
```

Her taşıma için doğrulama: tek kök commit; `git log --all --name-only` çıktısında hedef dizin
dışında dosya yok.

## Güvenlik taraması

- **gitleaks** (taşınan geçmişler): covenant/mcp, compliance-api, agent-sdk ve tekil dosyalar
  temiz. Prover geçmişinde 5 `generic-api-key` bulgusu, Prettier sonrası aynı satırdan 1 tane
  daha; hepsi kabul edilmiş yanlış alarm:
  - fixture'larda ve README istek örneğinde `payment_token_mint` alanındaki mainnet USDC mint
    adresi (`EPjF…`, açık anahtar);
  - `scripts/extract-vk-rust.mjs`'te VK sabitini üreten satırın şablonu (`Groth16Verifyingkey`
    tip adı).

  İkisi için `.gitleaks.toml`'a satır bazlı, dar istisna eklendi (commit'e bağlı parmak izi
  değil, `gitleaks dir` için de geçerli). Aynı dosyaya eklenen sahte bir sır yine yakalanıyor
  (yerelde doğrulandı). `gitleaks git --log-opts=HEAD` ve `gitleaks dir` temiz.
- **1 MB üstü blob:** yalnızca prover artefaktları, `apps/prover/artifacts/` geçmişinde:
  `payment.wasm` (2.345.849 ve 5.007.935 B) ve `payment.zkey` (1.111.529, 1.111.530 ve
  3.168.097 B). HEAD'de wasm 4,78 MiB, zkey 3,02 MiB. Önceden kabul edilmiş istisna.
- `.env`, keypair, `node_modules`, `dist` taşınmadı. compliance-api `.env.example` korundu;
  değerleri boşaltıldı.
